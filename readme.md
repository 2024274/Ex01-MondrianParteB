# Título

Para a componente generativa, optou-se pela criação de uma linha horizontal dinâmica e instável (com efeito de tremor) que rasga a composição geométrica rígida. A escolha da linha a tremer deveu-se à simplicidade das alterações, uma vez que ainda é preciso aumentar a improvisação dos códigos em si. A lógica por trás deste elemento baseia-se no cálculo de uma coordenada vertical (y) que se altera a cada frame através do motor do p5.js. A função "stroke(0)" garante que a linha/contorno mantém o preto regulamentar do estilo. A variável "y" fixa a linha, somando-lhe um valor gerado pela função "random(-3, 3)". Isto faz com que, a cada ciclo de renderização, a linha oscile aleatoriamente 3 píxeis para cima ou para baixo, gerando o efeito visual de 'tremor' contínuo na linha retangular.
